# Mobile app

Thư mục dành cho ứng dụng di động của Smart Rental Management System.

Framework chưa được chốt. Có thể chọn React Native/Expo nếu muốn dùng JavaScript/React, hoặc Flutter nếu chọn Dart. Ứng dụng mobile sẽ kết nối tới backend tại `apps/api`.

Khi chọn framework, khởi tạo source code của ứng dụng trong thư mục này.
