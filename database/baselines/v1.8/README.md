# Database V1.8 distribution baseline

Versioned installation baseline for SmartRentalManagement, originally copied from the adjacent workspace project `GocTro-SmartBuilding/Database V1.8` on 2026-10-16. This folder makes a Git checkout self-contained for NEW database installation. It is the current physical baseline; changes must use the approved database version process.

- `schema.sql`, `seed.sql`, `erd.md`, validators and `migrations/` are byte-for-byte source copies. `SOURCE_README.md` is the original README, including its historical notes; `SOURCE_DATABASE_CHANGELOG.md` is copied from the canonical project's `docs/DATABASE_CHANGELOG.md`. The source README's 77-check description is stale: the copied CORE SQL explicitly expects 78; native runtime verification passed 78/78.
- `PROVENANCE.json` records origin and SHA-256 hashes. `expected-catalog.json` was generated by installing the exact schema on an empty disposable PostgreSQL 18.6 database, without seed. It records table/column/default/constraint/index/trigger/function/type/sequence structure, excluding environment-specific owners/OIDs, row data and current sequence values. Arrays are sorted independently of database/OS locale so native and Docker default collations do not create false drift.
- `schema.sql` creates 40 application tables. The V1.8 Parking partial unique index is SQL authority; Prisma 6.12 cannot fully map its predicate.
- `seed.sql` contains synthetic identities and discarded-random-secret password hashes. It does not provide a known login password. It is not an idempotent operational data migration; the wrapper only permits it once on a verified V1.8 schema with all application tables empty.
- `migrations/V1_7_to_V1_8_recurring_parking_invoice_linkage.sql` is an upgrade artifact retained for review. Bootstrap never executes it. It is not a generic upgrade from demo/Prisma history.

Use the guarded npm commands in [DATABASE_V1_8_SETUP.md](../../../docs/10_operations/DATABASE_V1_8_SETUP.md). Do not bypass their preconditions by applying SQL to a populated target. Do not regenerate catalog/hashes to make unknown drift pass: investigate the difference and obtain an approved version/migration decision.
